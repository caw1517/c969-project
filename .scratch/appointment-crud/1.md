## What to build

Read stored appointments into the Appointments tab with Customer and User names and machine-local times, providing the shared read path for appointment operations.

## Acceptance criteria

- [ ] Read all stored appointments into a generic collection, join Customer and User names, and order by start then appointment ID.
- [ ] Keep Start and End UTC with Kind.Utc in models and the bound collection. Convert only when rendering controls or messages, using TimeZoneInfo rather than fixed offsets.
- [ ] Display a read-only, full-row selection grid with Customer, User, Type, Title, Start, and End; hide IDs and clear selection after binding.
- [ ] Show the machine-local time-zone label. Handle empty results and loading failures understandably.
- [ ] Verify displayed local times against stored UTC values, including dates on opposite sides of a DST transition. Use legal weekdays October 30 and November 2, 2026; account for the machine zone, which may not observe DST.
- [ ] Build successfully and demonstrate the database-to-grid path in the running application.
