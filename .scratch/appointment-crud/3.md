## What to build

Open a selected appointment, update its editable fields, and see the persisted result while retaining its original ownership and creation audit information.

## Acceptance criteria

- [ ] Require a selected row and prefill a modal editor, including local Start/End values and all optional text. Retain the original appointment ID and owner.
- [ ] Reuse the agreed Customer choices, required fields, text limits, local-zone display, and ordered Eastern business-hours validation.
- [ ] Check global overlap at save time, excluding only the appointment being edited by ID. Title-only and unchanged saves do not conflict with themselves.
- [ ] Persist edited Customer, text, and UTC times with parameterized SQL. Preserve UserId, createDate, and createdBy; update lastUpdateBy from the session and never write lastUpdate.
- [ ] Identify the row by its stable ID. Distinguish a missing row from an unchanged edit even when connector settings report zero changed rows.
- [ ] Use an Edit-specific exception path including overlap-query failure. Keep inputs after failure, return success only after persistence, and make Cancel write nothing.
- [ ] Refresh on success and distinguish refresh failure from save failure.
- [ ] Build and verify Customer/type/time edits, retained ownership and creation audit values, title-only and unchanged edits, collision with another appointment, invalid business hours, Cancel, and controlled Edit/query failure in the running app.
